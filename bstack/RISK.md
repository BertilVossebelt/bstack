# Risk levels

Give each performance or security decision or finding one of these levels:

- low: light slowdowns or small issues, only in rare situations.
- medium: slowdowns or errors that other users notice, in realistic situations.
- high: an outage, data loss or a data leak is possible.

Base the level on the possible use, not the expected use. Anyone with access can call the code from a script or an AI agent, in a loop or in parallel. Low expected use never makes a medium or high risk acceptable.
